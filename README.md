## 👋 About

**브라우저에서 문서를 다루는 프론트엔드 개발자**입니다.
임상시험 데이터 수집 시스템(EDC)을 만들면서, PDF 렌더링·텍스트 레이어·좌표 정합처럼 *"화면에 보이는 것과 실제 데이터가 어긋나는 문제"*를 최소 예제로 재현하고 글로 정리합니다.

- 🏥 **CNR Research** — 임상시험 EDC 프론트엔드 개발 (CDISC ODM 기반)
- 📄 `react-pdf` / `pdf.js` 로 300쪽짜리 문서를 가볍게 그리는 법을 실험 중
- 🤖 요즘 관심사: **에이전트가 읽기 좋은 저장소**, AI가 쓴 코드의 검증과 책임
- 🌱 MDN · Vite 한국어 문서 번역, 라이브러리 이슈 리포트로 오픈소스에 기여
